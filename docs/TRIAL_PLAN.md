# Folio 1.1.0 一周试用计划

适用于 3–5 位愿意试用的用户。尚未邀请任何人或发送消息；由发布者选择参与者及反馈渠道。安装包、使用指南和校验清单一起交付，提醒这是发布候选。

| 时间 | 使用任务 | 重点记录 |
| --- | --- | --- |
| 第 1 天 | 安装；打开已有 Markdown；写中文；保存；退出重开 | 安装名称、默认理解、输入、保存状态与内容是否保留 |
| 第 2 天 | 标题／粗体／代码旁用真实 IME；查找／替换；长文撤销 | 候选框、吞字、光标／选区跳动、卡顿及重现步骤 |
| 第 3 天 | 拖入图片；另存；把文稿和附件一起移到其他目录 | 图片是否保留，附件规则是否容易理解 |
| 第 4 天 | 编辑同一文件的外部版本；取消保存覆盖；另存一份 | 提醒是否明确，两个版本是否保留 |
| 第 5 天 | 导出混合文稿 PDF／Word；导入自己的模板；取消后重试 | 内容、层级、公式、表格、图片、模板确认是否容易理解 |
| 第 6 天 | 明暗主题、小窗口、系统缩放、第二台电脑 | 字体回退、窗口拖动、控件溢出、不同电脑的导出差异 |
| 第 7 天 | 连续写作至少 30 分钟；总结前三个摩擦点 | 写作舒适度、可理解性、是否愿意继续使用 |

异常恢复只使用可丢弃的测试文稿演练。不要为测试在真实工作文稿上主动断电；正常写作意外退出时记录恢复结果。

每个问题填写：版本、系统与缩放、输入法、操作步骤、预期、实际、是否可重复、是否影响文件内容。可从应用内复制问题记录模板。截图与文稿由用户自行匿名化后提供。

任何文稿丢失／无确认覆盖都暂停稳定版发布；核心输入或导出失败先修复；仅风格偏好单独归入后续改进。未发生问题不等于所有场景已通过，放行以发布验收矩阵为准。
