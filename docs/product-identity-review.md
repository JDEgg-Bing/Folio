# Folio · 轻页：产品身份与顶部交互验收

> 历史阶段记录；其中测试数量、界面与边界只对应当时构建。当前范围以 [1.2.0 发布验收](RELEASE_ACCEPTANCE.md)和[统一规范](DESIGN_SYSTEM.md)为准。原始日志与历史截图留在本地，不随源码公开。

本轮只处理产品身份、标题栏与菜单接入。上一轮写作画布、目录、设置和状态栏的视觉优化继续保留。

## 名称与图标

Folio 表达书页、文稿的意象；中文副名“轻页”强调轻量、日常和舒适。英文名称用于应用文件和系统窗口。根据后续调整，窗口左上角仅显示图标，不显示中英文名称。

图标由低饱和森林绿底色、暖白纸页、浅鼠尾草色折角和两条文字线组成。与界面强调色协调，强调写作工具的气质，不采用徽章、复杂字母组合或公司标志的表现方式。

- [原始图标](../assets/folio-master.png)
- [标题栏图标](../assets/folio-mark.png)
- [Windows 多尺寸图标](../assets/folio.ico)：16、24、32、48、64、128、256 像素。
- 图标由内置 Image Gen 生成；最终采用不透明输出，原始图标与多尺寸 ICO 保留在项目 assets 目录。
- 最终生成提示要求：整幅森林绿底色，中央暖白折角纸页，两条短文字线，简单几何形状，适合小尺寸；不包含字母、装饰、光效、边框或透明区域。

应用文件的 ProductName、FileDescription、InternalName 均已检查为 Folio，窗口与打包资源均使用同一套图标。原有默认偏好目录继续使用 `Markdown Editor`，避免更名后丢失用户的排版偏好；显式指定的测试目录保持有效。

## 顶部区域

44 像素标题栏统一容纳：23 像素图标、28 像素胶囊菜单、当前文档标题与未保存标记。右侧保留 Windows 原生最小化、最大化和关闭按钮。正文仍占主要空间。下方截图保留上一轮验收状态；后续已去掉图标旁的中英文名称。

标题栏使用 Electron 的原生 Window Controls Overlay；品牌与标题区域声明为拖拽区域，菜单按钮声明为不可拖拽区域。[Electron 官方标题栏交互说明](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions)说明了这种接入方式。

## 菜单入口与面板

文件、编辑、视图使用克制的浅底、细边框胶囊。Hover 提高背景与文字对比；按下轻微缩小；展开时使用灰绿色高亮。面板使用 11 像素圆角、柔和阴影、接近不透明的背景与轻微模糊，减少正文透过面板干扰菜单阅读。

命令标签、快捷键、勾选状态和二级菜单沿统一基线组织。菜单可以通过 F10/Alt、方向键、Home/End、Enter、Escape、文字匹配及鼠标操作；点击正文收起，执行编辑操作前恢复原有编辑焦点。小窗口为二级面板预留空间。

原有原生菜单保留为隐藏的快捷键来源，与自定义面板共用命令定义。普通编辑命令调用 Electron 原有命令；菜单的撤销/重做在编辑器中转发到既有历史快捷键，普通输入框仍使用原生命令。未修改编辑器历史实现。

## 动效

- 主菜单展开：170ms，`cubic-bezier(.16, 1, .3, 1)`；透明度、5 像素位移与 0.96 → 1 的缩放组合。
- 主菜单收起：110ms，`cubic-bezier(.4, 0, .7, 1)`；沿原路径返回。
- 变换原点按实际触发按钮中心计算，窗口缩放时重新定位。
- 二级菜单展开：140ms，从父菜单边缘出现。
- 系统“减少动态效果”偏好生效时关闭缩放、位移和菜单动画，同时使用实色背景。

没有增加大块品牌展示、厚工具栏、强渐变、发光或装饰性动画。

## 保持不变

文档模型、Markdown 功能、CodeMirror 编辑核心、文件读写、保存与 dirty tracking、PDF/DOCX 导出、公式、图片、表格、引用以及设置项数量保持不变。本轮只在 UI 与原有菜单命令之间增加必要适配。用户字体、正文宽度、主题和排版偏好继续生效。

## 仍不满意的地方

16 像素图标的细节仍较柔和。系统文件选择和未保存确认继续采用 Windows 原生外观，与应用菜单仍有风格差异。鼠标拖拽未获得可靠的自动化验证。长期写作的舒适度需要真实使用反馈，本轮运行检查不能代替长期体验。

本轮开发停止于此。
