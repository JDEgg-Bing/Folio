# Folio · 轻页 1.2.0 使用指南

## 写作与保存

直接写 Markdown。光标进入段落时显示标记，离开后显示阅读样式；点击公式、图片或表格可编辑源码。首次欢迎页可关闭，示例文稿需要主动打开。

Ctrl+N 新建，Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+F 查找／替换，Ctrl+Z 撤销，Ctrl+Y／Ctrl+Shift+Z 重做，Ctrl+Shift+O 切换目录，Ctrl+Shift+E 导出 PDF，F11 全屏，F1 指南。F10／Alt 进入菜单，方向键、Enter、Escape 导航。

“已保存”表示当前内容已写入磁盘；“已修改”表示还有修改未保存；“未保存”表示未关联文件。导出不会自动保存 Markdown。标题可建议首次保存的文件名，修改标题不会重命名已有文件。

支持 UTF-8 有／无 BOM，保留检测到的 LF／CRLF；混合换行符会提示，保存时统一为主要换行符。其他编码需先转换为 UTF-8。

## 文稿保护

新建、打开、退出均有未保存确认；保存失败、取消另存为、保存中继续输入不会把未写入内容标为已保存。正式菜单移除重新加载／开发者工具，并拦截刷新快捷键。

编辑时约每 600 毫秒更新本地恢复草稿，持续输入也会更新。写盘异步，不能保证断电前的最后一小段输入；草稿上限 20 MB，不代替 Ctrl+S，也不自动覆盖 Markdown。

异常退出后可恢复或丢弃草稿；恢复文稿仍需手动保存。点击“丢弃恢复草稿”先显示确认说明，再点击“确认丢弃草稿”才移除草稿；Esc 不会丢弃。正常“不保存”退出／切换文稿会清除旧草稿。草稿位于本地数据目录 `recovery/draft.json`；损坏时保留原文件，并尝试创建 `.invalid-*` 副本。

其他程序修改或删除当前文件后，切回应用会提示；每次保存前比较完整文件内容，发现差异默认取消覆盖。可另存一份或主动确认覆盖。本版没有自动合并、持续文件监视或跨程序写锁；检查与写入之间极短的并发修改窗口仍存在。

## 安装与文件打开

安装注册 Folio 为 `.md`／`.markdown` 的“打开方式”选项，不更改默认应用。可在 Windows 中自行选择默认编辑器。再次启动会激活现有窗口，传入文件也经过未保存确认。当前为单文稿窗口，每次处理一个文件。

中文安装向导依次说明安装位置、快捷方式和安装结果，默认安装在当前用户的 Programs/Folio 文件夹，无需管理员权限。桌面快捷方式可选。若检测到旧版，可选择在新版安装成功后整理旧程序；请使用与旧版不同的安装位置。卸载只移除程序及入口，资料保留，重装可继续使用。当前安装包尚未签名。

## 图片附件

拖入图片前先保存文稿，托管图片写入同名 `.assets` 文件夹。通过应用另存为时迁移使用中的托管附件。

移动／分享 `.md` 时一起复制同名 `.assets` 文件夹；其他相对路径图片也要保留原目录。单独复制 Markdown 不会携带图片；网络图片不会自动下载成附件。

## 排版与字体

外观设置只调整写作画面，不修改 Markdown 或保存状态。字体需安装在本机，设置窗口提示缺失首选字体及当前可用回退字体。

PDF 和内置 Word 共用所选“默认文稿／学术报告／简洁阅读”正式版式，不读取编辑器外观；主题与强调色不进入成稿。Word 模板导出使用已确认模板格式。

PDF 固定分页；Word 保留可编辑文字、原生表格、可转换的 OMML 公式、图片和链接，但接收电脑的字体、Word 版本和兼容软件可能改变分页。应核对内容、层级、编号、引用；不承诺三种呈现逐像素一致。

## Word 模板

导入 DOCX／DOTX，核对正文、标题和题注映射，逐项确认冲突后保存／导出。取消或失败保留选择，可重试。已保存模板和默认选择重启后可复用。

内置导出版式使用三个单选卡片，选好后点击“选择保存位置”。删除已保存模板时先确认，默认取消；仅删除轻页保存的副本，原始 Word 文件与成稿保留。

只识别已经应用的格式，不把文字描述的要求变成规则。不完整重建特殊封面、多节／多栏、文本框、浮动对象、SmartArt、宏、插件；多套表格样式不按用途自动分配。以模板提示和导出诊断为准。

## 本地数据与反馈

“帮助 → 关于轻页”显示版本；“问题反馈”提供记录模板和数据位置。打开数据目录时复制随包发布资料供查看。

默认 `%APPDATA%/Markdown Editor` 保留旧设置、模板和草稿；卸载不主动清除。文稿在用户选择的位置，卸载不会删除文稿。应用没有账号、云同步、遥测、自动更新；升级使用发布渠道的新安装包。

向提供安装包的渠道提交版本、可重复步骤、预期和实际结果；附文稿前自行去除私密内容。
