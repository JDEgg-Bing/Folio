# Folio · 轻页：视觉与交互规范

2026-10-03。此规范覆盖安装、升级、首次启动、写作、设置、模板、导出、恢复、错误、退出、卸载与重装。以现有轻页品牌和写作画布为基础，避免以新主题覆盖用户已经保存的排版偏好。

## 产品身份与基调

产品名称 Folio · 轻页；系统可执行文件 Folio.exe。标题栏保持既有“只显示图标”的设计。安装、任务栏、快捷方式、关于与卸载入口使用 assets/folio.ico 的同一纸页标志，应用内使用其原始 PNG。

正文优先，背景使用温暖纸色和安静墨色。品牌基准强调色是苔绿；用户选择的其他强调色适用于应用内，安装器使用稳定的品牌色和系统主题。安装器不读取个人偏好文件。

## 按钮、键盘与提示

- 一个操作区只保留一个主要动作，放在最右侧，使用强调色实底。普通动作使用细边框。删除、覆盖、丢弃使用明确动词和危险色；不以颜色单独传达含义。
- 所有按钮具备默认、悬停、按下、键盘焦点与禁用状态。异步操作显示具体文字、禁用重复提交；不会把“取消”伪装成失败。
- 标准弹窗以 dialog 语义提供焦点约束，初始焦点有明确规则，关闭后返回先前操作位置。Esc 取消；未决定的恢复草稿不因 Esc 丢弃。
- 未保存确认默认“保存”；外部覆盖与删除默认“取消”；恢复默认“恢复文稿”。丢弃恢复草稿需要第二次明确确认。
- 成功用温和绿色状态提示；处理过程用中性色。失败说明发生了什么、当前内容是否保留、下一步怎么做。持续性问题不自动消失。处理期间不显示无效关闭动作。
- 140ms 颜色过渡，减少动态效果关闭动画；高对比模式尊重系统颜色与清晰边框。截图不能证明完整屏幕阅读器合规。

## 用户流程

| 顺序 | 流程 | 设计与数据约定 |
| --- | --- | --- |
| 1 | 安装 | 中文向导：欢迎 → 位置／快捷方式 → 确认 → 进度 → 完成。当前用户安装，不索取管理员权限；不更改默认 Markdown 应用。取消尚未执行安装时不改程序资料。 |
| 2 | 升级 | 新向导版使用稳定 AppId；保留设置、模板、草稿和文稿。检测旧 Squirrel 安装时给出默认不选的整理旧入口选项，只在交互向导中明确选中且新版安装成功后运行旧卸载器；禁止安装到旧程序目录中。保留历史构建能力。 |
| 3 | 首次启动 | 三个短步骤：写 Markdown、Ctrl+S 保存、按需导出。帮助留在 F1；不要求新用户先读完整手册。 |
| 4 | 写作与查找 | 正文是主区域，菜单、目录和查找用同一文字色、焦点与强调状态；原排版偏好保持。 |
| 5 | 设置与模板 | 统一弹窗框架、控件高度、说明、提醒、按钮。设置即时生效；模板导入后可核对，删除先确认，导出失败保留选择。 |
| 6 | 保存与冲突 | 保存／另存为使用系统文件选择器。未保存确认和外部覆盖警告使用应用统一弹窗，取消保留文稿。 |
| 7 | 导出 | 统一单选版式卡片 + “选择保存位置”；Word 模板入口与 PDF 共用版式描述。取消不生成文件、不清空选择；成功说明成稿名称。 |
| 8 | 恢复与错误 | 时间、名称和预览明确；恢复仍需保存。错误／提醒可读、可关闭，危险操作有确认，磁盘原文件不会因看提示而改写。 |
| 9 | 退出 | 无修改直接退出；有修改先处理统一保存确认，保存失败仍留在写作界面。 |
| 10 | 卸载与重装 | 卸载明确列出移除项和保留项，图标／名称／背景／字体与安装相同；不把清除个人资料混入卸载。重装继续使用原本地资料。 |

## 系统边界与安装器

打开、保存和文件覆盖的路径选择由 Windows 文件对话框提供；标题、按钮动词和文件类型与应用约定统一，导航、权限提示和系统焦点遵循 Windows。安装取消、卸载确认和卸载完成提示由安装框架的 Windows 消息窗口提供，统一中文字体、底色和具体说明，保留系统“是／否”按钮与图标。渲染进程崩溃时保留原生重新打开／退出应急提示。系统安全拦截、签名提示和高对比配色不能伪装或绕过。

新的完整向导使用 Inno Setup 6.7.3，来源为 [官方版本下载](https://jrsoftware.org/isdl.php)，下载后核对 Authenticode 发布者 Pyrsys B.V.。向导配置使用 [官方明暗样式与背景能力](https://jrsoftware.org/ishelp/topic_setup_wizardstyle.htm)。安装器保留 Windows 控件和原生键盘焦点；统一品牌、底色、字体、文案、层级和步骤，不声明系统控件与网页按钮逐像素一致。

构建：先完成 Forge package，再配置 FOLIO_ISCC 或使用 out/build-tools/inno/ISCC.exe，运行 node scripts/build-installer.cjs。--test 构建使用独立安装目录、独立 AppId、独立 ProgID 和测试快捷方式，避免替换现有安装。生产安装器与隔离验收器来自同一模板；隔离版不注册默认扩展名，也不触碰旧版卸载器。
