# Word 模板导出

在「文件 → 导出 Word…」或「文件 → Word 模板…」中导入 DOCX / DOTX。软件自动分析页面、样式继承、正文段落和重复出现的直接格式，展示识别依据、段落样本和不确定项。核对正文、主标题、一级 / 二级标题及图题 / 表题即可；其余映射放在「更多内容映射」中。

若识别有误，选择模板里的另一个已有样式或段落样本，无需重新输入字体、字号或行距。兼容性警告必须明确勾选后才可保存 / 导出。正文映射必须存在。未确定的其他角色明确使用基础版式或继承正文。

「保存模板」和「按此模板导出 Word」都会保存已确认的模板；后者接着导出当前编辑器快照。模板可以重命名、删除，或设为默认。选择「默认文稿（内置版式）」继续使用原有三种 Word 导出版式。PDF 和 Appearance 独立于模板。

## 分析与保留范围

- 页面大小、横纵向、页边距、装订线、页眉 / 页脚距离、原生页码字段、首页不同、奇偶页不同。
- 原有样式体系、docDefaults、basedOn 继承、中文 / 西文字体（包括主题字体和分开的文字 run）、字号、加粗、行距、段前段后、缩进、对齐、大纲级别、与下段同页和段前分页。
- 正文、主标题、六级标题、引用、列表、代码、公式、表格文字、图题和表题的角色映射。
- 无明确样式时按重复段落格式归类；短标题编号用于推断层级，并标为需核对。正文候选排除表格和文本框中的使用频率，防止大表格抢占正文映射。
- 保留命名样式、主题、字体表、编号定义、页眉页脚及其依赖的嵌入图片。规范的命名样式直接用于导出段落，以维持页眉中的 STYLEREF 目标。直接格式样本生成可编辑的段落样式。
- 首个表格提供样式、边框、底纹、单元格留白和首行 / 数据行规则。新表格仍按 Markdown 的实际列数与内容确定列宽；不会复制示例表格的合并关系。

导出从完整 Document Model 快照生成正文，再放入模板的版式部件。保留 Markdown 中的粗体 / 斜体、嵌套列表、引用、图片、题注、表格、LaTeX 和公式编号。常见公式为原生 OMML，可在 Word 编辑；不支持的公式沿用现有视觉降级并明确报告。内部引用使用书签链接，外部链接使用原生超链接。原模板正文、脚注、封面文字不复制，也不会以隐藏部件留在导出包内。

图题取图片替代文字及已有图编号；表编号取 `{#tbl:...}`。独立的 `表 1 …` / `Table 1 …` 或 `图 1 …` / `Figure 1 …` 段落使用相应题注映射。编号和引用文字由 Markdown 文档模型在导出时确定；在 Word 内继续增删图表后，不提供自动 SEQ / REF 重新编号。

## 保存方式

模板保存在应用用户数据目录的 `word-templates` 文件夹。每份模板是一个原子写入的 JSON，包含版本、名称、原 DOCX / DOTX 压缩包、识别结果、用户确认的映射和兼容性确认。默认模板另存。重新启动后直接读取已确认映射，原文件移动或删除也不影响复用；不会重新分析已保存模板。

导入上限为 25 MB，解压后上限为 100 MB / 4,000 个部件，格式候选上限为 1,500。损坏 XML、实体声明、无效 ZIP / 部件路径、损坏页眉页脚关系、宏、ActiveX 和嵌入 OLE 对象会明确拒绝。所有模板 IPC 请求检查主窗口来源；渲染进程只能发送模板 ID 和已有候选映射，不能提供任意文件路径或 XML。

## 明确限制

- 仅支持常规 Transitional DOCX / DOTX；旧版 DOC、宏文档和 Strict OOXML 要先在 Word 中另存为普通 DOCX。
- 多分节统一为末节版式，继承前节页眉页脚；多栏统一为单栏。两者都在确认前警告。不会重建特殊封面、正文文本框、浮动对象、SmartArt 或内容控件。原文件和库内源压缩包保留。
- 样式和题注识别是启发式分析，直接格式无法证明语义；不确定映射显示证据并允许修正。缺少样式定义可按样本导出；没有任何可识别段落或样式的文档会拒绝。
- 多套表格样式、合并表头、特殊单元格结构只采用首个表格的基础规则。列表采用匹配编号样本；复杂图片项目符号、专用编号插件不保证完整复现。
- 页眉页脚中依赖原正文书签 / 文档属性的字段会保留并警告，需在 Word 中核对。外部链接图片和活动资源不能作为保留部件，导出会明确报错，无法静默丢失。
- 字体必须在使用 Word 的电脑上可用；没有安装时由 Word 替代。本轮不安装或嵌入新的字体。

## 验证

新增 55 项自动测试：49 项分析 / 原生导出 / 模板库测试，以及 6 项导出与 IPC 生命周期测试。现有编辑器、文件、公式、图片、表格、引用、PDF、普通 DOCX、Undo / Redo、dirty tracking 和 Appearance 回归测试继续运行。

可重现的桌面验收：`scripts/word-template-acceptance.cjs`（使用独立用户目录），生成并导入普通正式报告、科研 / 技术报告、大量直接格式文档；检查识别界面、模板保存、重启复用、内置 Word 导出、未保存快照和撤销 / 重做。`scripts/word-template-word-acceptance.ps1` 在 Word 中打开参考和导出文件，比较字体 / 段落 / 标题 / 页眉页脚，并在正文与表格内插入文字、保存后再次打开。`scripts/word-template-pages.py` 渲染 Word 原生 PDF 的全部页面，供逐页视觉检查。

本机 Word 16.0 实际验收中，三类导出均有 2 个可编辑表格、6 个原生公式、1 张图片、3 个内部超链接。正文为报告模板指定的 11 pt 宋体 / Arial 或技术模板指定的 12 pt 仿宋 / Times New Roman；首行 24 pt、1.5 倍行距、段后 6 pt，主标题 20 pt 居中，一级标题 16 pt，并保留技术模板的段前分页。原生 Word 打开、正文和表格编辑保存往返均通过。正式 / 直接格式输出为 2 页，技术输出为 4 页。技能默认 LibreOffice 渲染器在此 Windows 环境不可用，因此使用实际 Word 导出 PDF 并渲染 PNG 检查，未安装新排版软件。

实现依据：Word 样式继承遵循 Microsoft 的 [BasedOn 定义](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.basedon?view=openxml-3.0.1)，页眉页脚按 [WordprocessingML 部件关系](https://github.com/OfficeDev/open-xml-docs/blob/main/docs/word/how-to-replace-the-header-in-a-word-processing-document.md)保留。
