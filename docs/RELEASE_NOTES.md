# Folio · 轻页 1.2.0

2026-10-04 · 首个公开预发布 · [`v1.2.0`](https://github.com/JDEgg-Bing/Folio/releases/tag/v1.2.0)。旧 V1 安装验收不代表本版本放行。

## 本版本

- 建立覆盖安装到卸载的视觉与交互规范；统一控件尺寸、按钮层级、危险动作、焦点和提示状态。
- 使用完整中文安装向导，统一纸页标志、背景、中文字体和文案；安装位置、快捷方式、取消、进度、完成和卸载均可核对。
- 首次欢迎缩短为三个写作步骤；完整指南保留在 F1。
- 未保存和外部覆盖使用应用内统一确认；内置导出版式改为单选卡片与“选择保存位置”。
- 设置、Word 模板、恢复和帮助共用弹窗框架；明暗、200% 应用缩放和小窗口可操作。
- 删除模板默认取消，丢弃恢复草稿需要第二次确认；处理、成功、失败提示保持一致。

## 延续 1.1.0 的能力

- 统一 Folio／轻页名称、图标、明暗菜单、设置、目录、查找和提示。
- 提供公式、图片、表格、引用、长文档目录、PDF／DOCX 与 Word 模板。
- 移除刷新／开发者入口；新增本地恢复草稿、外部修改检查与默认取消覆盖。
- 新增安装生命周期、旧快捷方式清理、单实例、系统文件打开；保留旧数据目录与 Squirrel 包标识。
- 保存／打开失败统一为应用内提示；Word 导出取消／失败保留选择；导出不改 Markdown 保存状态。
- 新增欢迎、指南、示例、关于、版本、反馈模板、字体回退及排版范围说明。
- 自动准备 7-Zip，随包附许可证、资料、依赖版本与 SHA-256 校验。

## 开源准备

自有代码、文档与品牌素材采用 MIT，署名 2026 Folio Contributors。双语首页、真实明暗界面截图、贡献／安全／行为准则、Issue／PR 模板、Windows 自动检查与依赖更新配置已准备。

第三方许可证、完整上游源码归档与 LGPL 库替换重建说明随包提供。新的验收结果绑定完整应用哈希，公开发布资料与原始本地日志分开。未提供旧版包时，升级明确记为 NOT_RUN。

## 已知限制

验收环境为 Windows 11 x64。已实际执行隔离安装、向导版 1.1.0→1.2.0 升级、卸载、重装和资料读取。真实旧 Squirrel 1.0.0 迁移、IME、物理鼠标、多显示器 DPI 与第二台电脑仍需验证。

草稿不能保证最后一小段输入，不能替代保存。没有外部文件自动合并、多标签、云同步或自动更新。

模板不解析文字要求，不完整重建特殊封面、多节多栏与浮动布局。字体不打包；缺失时回退，跨电脑 Word 分页可能改变。

通过 [GitHub Issues](https://github.com/JDEgg-Bing/Folio/issues/new/choose) 反馈使用问题，安全问题按[安全政策](https://github.com/JDEgg-Bing/Folio/blob/main/SECURITY.md)私密报告。安装包未代码签名。最终结果以当前发布验收和实际安装包为准。
