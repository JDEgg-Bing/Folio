# 正式文稿 PDF 导出与渲染修复

2026-10-02 更新：PDF 与 Word 已采用独立于编辑器的共享正式文稿版式及三个导出预设。以下旧说明中关于共用编辑器外观的部分已被替代，最新设计与验收见 [正式文稿排版](manuscript-export-layout.md)。

## 用户入口

文件 → 导出 PDF…（Ctrl+Shift+E）。用户选择目标位置；取消不产生文件。完成后显示克制的状态提示，不改变文档的已修改／已保存状态。导出包含尚未保存的当前内容，不要求先保存 Markdown。

## 两个独立表现层

编辑器：Markdown Source → Document Model → CodeMirror 实时预览。

导出：当前 Markdown 快照 → 完整 Document Model → PdfRenderer 正式文稿 HTML → 隔离的隐藏窗口 → PDF ExportAdapter → 原子写入用户选择的位置。

已有 ExportAdapter 的版本及完整性检查继续生效。导出完整解析与编辑器视口解析独立，不依赖活动行、光标、预览开关或深色模式；不读取或打印 Editor DOM。

正式文稿使用白色 A4 页面与固定纸张边距；字体、字号、行距、段间距、标题层级等通过已有 WritingAppearance 字体和排版变量传递。中文与英文保留独立的本地字体分配；公式使用 KaTeX，字体在构建时嵌入 CSS，不访问网络。本地图片嵌入文稿，隐藏窗口等待字体与图片加载完成后生成 PDF，随后销毁并清理临时文件。

当前支持标题、普通段落、强调、行内代码、代码块、有序／无序列表、引用块、分隔线、行内／块公式、三线表、本地图片与图注、可解析的交叉引用以及普通外部链接。内容按 Document Model 顺序输出。Markdown 的显式换行保留；原始 HTML 以安全文本输出。

## 编辑界面修复

- 非活动引用行隐藏 `>`，轻微缩进、1px 低对比度竖线、稍弱文字；活动行保留源码标记。引用预览细线不再被衬线预设的 `quoteBorder=false` 隐藏。
- 普通顶层正文使用 `--writing-paragraph-align: justify`，保留首行 2em 缩进与自然的末行。标题、列表、引用、代码、公式块、表格、图片和图注不应用正文对齐规则。
- 原目录问题来自 scroll spy 按视口最顶端取正文位置，而目录跳转故意将标题放在顶部留白之后，因此返回上一节。ReadingTracker 让显式跳转立即确定章节，并在程序滚动或重测量期间保持；滚轮、触摸、正文鼠标操作及导航键释放此状态，恢复实际滚动位置判断。文末定位按需补足底部留白继续生效。
- 窗口标题与状态栏共同使用 `resolveDocumentTitle`：第一个 H1 优先，无 H1 时已保存文档使用文件名（含扩展名），未保存文档使用“未命名文档”。保存状态仍独立判断，不重命名实际文件。

## 导出限制

- 本轮固定为 A4，不提供复杂模板、目录页、页码或页眉页脚系统。
- 使用 `break-after: avoid` 让标题与随后的内容尽量相邻；段落控制孤行，表格重复表头、普通行和图片尽量不跨页。超过单页高度的行／图片组合、特别宽的表格或长公式仍可能需要用户调整内容；没有实现复杂的跨页公式和跨页表格续表系统。
- 网络图片与编辑器保持一致，不自动下载；未保存文档的相对图片路径无法定位。不可用图片会保留提示及图注，并在导出完成信息中报告。
- 无效公式保留源码，缺失或重复交叉引用报告诊断；不会静默省略。字体沿用本机可用字体，指定字体缺失时走既有字体回退。
- 原始 HTML 不执行；高级 Markdown 插件、脚注等不在本轮支持范围。
- 接收 20 MB 以内的源码快照；同一时间导出一个文件。

## 验证

桌面验收通过 `scripts/pdf-acceptance.cjs` 执行。现有长文档没有“5.2／6”两节，因此在输出目录创建副本并添加长段落及文末第 6 节，不改变原测试文件。点击第 6 节后标题在视口上方约 38px，目录保持第 6 节；后续滚轮上移后高亮回到 5.2。进入引用行可见 `>`，离开后隐藏并显示细线和弱化文字。窗口和状态栏名称、32px 首行缩进、justify、导出取消、保存状态与源码不变均通过。

实际从深色编辑界面导出 4 页 A4 PDF，逐页查看渲染后的 PNG：中文、英文、公式、三线表、引用、图片、标题和分页正常，无编辑器 UI。文本提取确认文稿内容及顺序；嵌入字体包含 SimSun、Times New Roman 与 KaTeX。测试文件故意包含网络图片、无效公式和缺失引用，导出诊断如实报告。桌面操作由自动化执行，截图由代理查看，不冒充用户亲自验收。
