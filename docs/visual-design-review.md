## 1. 原界面的主要问题

原界面的视觉状态分散：目录与正文缺乏明确的主次，设置像一张参数表，关闭按钮的点击范围与反馈不足，错误提示没有深色配色。实际运行时还发现：

- 设置窗口在普通高度下需要滚动才能找到“完成”，缩小窗口后更明显。
- 深色模式的查找/替换栏保留了默认白色控件，按钮文字不清楚，与其他界面割裂。
- 目录主要依靠缩进表达层级，当前章节缺乏明确定位标记。
- 预设名称强调“科研文书”，给个人写作带来不必要的专业工具气质。

## 2. 优化后的核心原则

正文优先：保留完整写作画布，不增加工具栏、卡片或装饰性组件。温和的纸色与墨色构成明暗底色，低饱和绿色仅用于定位、选中与操作反馈。

一致的界面语言：界面使用稳定的系统无衬线字体，正文继续使用用户选择的字体。目录条目保留与正文相同的字体，标题、按钮与提示使用统一界面字体。边框、圆角、控件高度、悬停、按下、键盘焦点和滚动条共享视觉变量。

克制的层次：设置窗口使用轻微背景模糊和柔和阴影，写作区保持平整。过渡为短暂的颜色变化，尊重系统减少动态效果设置；不添加持续动画。

保留审美自由：字体、字号、宽度、行距、段间距、标题比例、紧凑/居中布局、引用与行内代码样式继续即时生效。两种预设只更改显示名称，所有数值与持久化标识保持原样。

## 3. 修改区域

| 区域 | 改动及作用 |
| --- | --- |
| 主窗口 | 明暗背景、文字与界面色阶统一；启动背景随系统主题匹配，减少加载时的底色跳变。 |
| 正文与查找栏 | 保留排版算法与用户参数，统一光标、选区、匹配高亮、输入框、按钮及提示样式；修复深色白色控件。 |
| 目录 | 区分一级与较深标题的字重/颜色，保持原缩进与 28px 虚拟行高；增加轻微悬停、按下和焦点反馈，当前章节用低饱和底色与细定位线；补充空目录说明。 |
| 设置 | 分为预设、文字、阅读节奏、页面与更多排版细节；增加简短说明；固定标题和完成操作，只滚动设置内容；统一控件对齐、尺寸与状态。 |

| 滚动条 | 编辑器、目录、设置及横向内容共享细滑块与悬停/按下色阶，保持点击范围。 |

## 4. 保持不变的部分与原因

- Markdown 与 Document Model、CodeMirror 核心、解析、实时预览、图片/公式/表格/引用管理：均不修改，避免视觉工作影响文稿内容或编辑行为。
- 文件读写、保存、dirty tracking、关闭保护与 Undo/Redo：均不修改，继续沿用已验证的状态与数据逻辑。
- PDF/DOCX 的导出代码与排版参数：均不修改，仅调整应用内导出提示的视觉样式。
- 所有排版设置的键、范围、默认值、预设参数与存储格式：保持原样，避免覆盖用户习惯或改变导出结果。
- 原生标题栏、菜单、打开/保存/导出文件对话框、未保存确认与系统错误对话框：保留系统实现与快捷键。全面自绘会扩大窗口与文件交互改动范围，超出此次视觉优化边界。
- 目录虚拟滚动、章节跳转、展开/关闭与小窗口覆盖模式：保持现有逻辑；原目录没有章节折叠功能，本轮也没有增加。

## 5. 仍然存在的问题与检查边界

原生标题栏、菜单及系统对话框依然受 Windows 主题与系统版本影响，无法与应用内控件逐像素一致。深色原生菜单已现场复核，所有入口与快捷键保持原样。

现有明暗主题跟随系统，没有独立主题选择或 UI 密度开关；本轮遵循不新增设置项的要求，没有补充这些选项。历史默认排版仍为衬线字体与较宽正文，用户可通过既有设置改为其他阅读习惯。

默认图片素材可能包含白色背景，深色模式下仍会显示原图底色；不修改用户图片内容。

截图、运行检查和短时阅读可以确认层级、布局与反馈，没有进行多日使用、长时间疲劳研究或完整屏幕阅读器审计。已提供清晰键盘焦点、减少动态效果和强制色模式的基本样式支持，不据此声明完整无障碍合规。
