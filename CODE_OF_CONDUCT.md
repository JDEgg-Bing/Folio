# 行为准则 / Code of conduct

本准则适用于 Folio 的 Issues、PR、讨论及其他项目社区空间。

尊重不同经验、语言和背景的参与者。围绕问题与方案讨论，提供清楚、善意的反馈；接受更正，为他人学习留出空间。不接受骚扰、歧视、威胁、人身攻击、发布他人私密信息或持续扰乱讨论。

维护者可移除违规内容、关闭失焦讨论，并按严重程度警告或限制参与；应公平处理，保护报告者隐私。

使用 GitHub 内容举报功能报告违规；敏感或紧急投诉通过 [GitHub 私密举报渠道](https://support.github.com/contact/report-abuse)提交，不在公开讨论中转发私密证据。该渠道由 GitHub 处理，项目尚未设置独立投诉邮箱。漏洞报告遵循[安全政策](SECURITY.md)。

## English

This policy applies to Folio Issues, pull requests, discussions and other community spaces. Respect participants with different experience, languages and backgrounds. Discuss ideas and behavior, give considerate feedback and accept corrections.

Harassment, discrimination, threats, personal attacks, disclosure of private information and sustained disruption are unacceptable. Maintainers may remove content, close discussions, warn participants or restrict participation according to severity, while applying the rules fairly and protecting privacy.

Use GitHub's content-reporting tools. Submit sensitive or urgent complaints through [GitHub's private abuse-report channel](https://support.github.com/contact/report-abuse), handled by GitHub, rather than posting private evidence publicly. The project has no separate private conduct mailbox. Report vulnerabilities following the [security policy](SECURITY.md).
